# Telegram Interview Prep Bot

A Telegram bot that helps students prepare for technical interviews.

## Features

- User registration
- Interview question bank
- Random questions
- Answer reveal system
- PostgreSQL database
- SQLAlchemy ORM

## Tech Stack

- Python
- PostgreSQL
- SQLAlchemy
- python-telegram-bot

## Commands

/start - Register user

/question - Get interview question

/answer - Show answer
